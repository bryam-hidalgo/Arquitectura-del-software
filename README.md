# Arquitectura-del-software
Este repositorio será usado para almacenar todo el trabajo práctico que contiene el curso de Arquitectura del software

### Notas aclaratorias
- Cada actividad se entrega en una carpeta por separado
- Dentro de cada carpeta encontrará 1 archivo en word y 1 en pdf llamados "Entregable Actividad (numero de la actividad)", que tienen la misma información y contienen la resolución de la actividad propuesta
- Dentro de cada carpeta encontrará 1 carpeta llamada Diagramas que contiene las imágenes de los diagramas que están en el entregable enumarados con el mismo orden en el que estan en el entregable
